## Recommendation

Build one tools-only free Regular seed-1 route from an empty task-owned save to the first acknowledged Imprint foundation. Include one Pocket tales Folio binding on the way. Stop at the first foundation, 14 calendar days, or 1,800 wall seconds, whichever occurs first. A wall guard or horizon without foundation is a useful partial result, never endpoint PASS. Fourteen days is a bounded observation window around the master plan's early Imprint interval, not a predicted duration or new balance target.

Use the actual Classic shell and Core wallet, with a tool-installed virtual clock before any page script. Do not extend the historical finite-cap policy in place. Two new tool files are sufficient in the proposed lease. No product adapter is presently justified: the existing extension API already exposes fixed commands. If native startup, rendering, timer scheduling or owner recovery cannot work under this clock, stop with that exact prerequisite. Do not patch product guards to make the run proceed.

This answers one practical question: can a fresh free route earn the first Imprint through current acknowledged owners, and where does it spend time? It does not measure six-week capstone pacing. Six weeks, premium calendar ratio >=55%, layer 2/3 ratio >=80%, and Away remain binding later.
