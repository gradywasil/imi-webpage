## Recommendation and honest ordering

Recommend only `game-speed:1`, 150 earned DB for permanent x1.25 game time, including offline. Keep Typist Speed at literal 1. Initial ordinary prerequisite is exactly the approved catalogue rule: introduction complete, acknowledged reward state ready, previous tier owned. Tier 1 has prior tier 0, so it needs no earlier speed receipt. It does not require lamp3, a Printing number, Estate, mastery or a new ordinary purchase. The proposed funding milestones are earning opportunities, not extra purchase prerequisites. Lamp's existing lamp3 initial prerequisite remains separate.

Game speed benefits typists, keepers, Hold, production timers and income together through the existing single speed hook. Typist speed would need a new typist-factor seam and residual-timer conversion while leaving the other bottlenecks unchanged. Game speed still needs prerequisite work across current owners; the presence of `speed()` is not implementation acceptance.

Current named maximum is 109 original DB plus the approved LG-10A 6 DB, or 115. Without Lamp, 150-115=35 DB is missing. After Lamp, 115-100=15 and 150-15=135 is missing. Recommend seven meaningful Gold milestones for 5 DB each, adding exactly 35. This is the minimum number of rows that supplies 35 while keeping each new Gold allocation within the master plan's 3-5 DB range. It is a bounded tranche, not a claim that seven awards are globally the only possible design.

With every named source earned and unspent, 115+35=150 buys speed and leaves 0. Buying Lamp first leaves 50 after all seven additions, still 100 short of speed. Buying speed first leaves no funding for Lamp. This package supports speed-before-Lamp only; it neither funds both nor promises another tranche. The player may prefer Lamp and defer speed. A player missing existing DB milestones needs correspondingly more of those existing sources. No guaranteed acquisition date follows from maximum-pool arithmetic.

These are substantial Imprint/Estate/Works milestones. Full funding can arrive late and requires deliberate continued progression, including three Estates and fifty first-play editions. It is not an early-game speed offer. Natural ordering and utility require later playtesting. If the owner wants speed soon after Lamp, defer that ordering rather than invent the additional 100 DB or front-load 135 solely for a purchase demonstration. The unapproved 120 ceiling and 114 reserve are not used or approved here.
