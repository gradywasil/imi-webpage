# LG-08I mastery first, then Auto-challenge

2026-10-15. CANDIDATE, UNAPPROVED. Documents only. A10 is locally accepted under LG-08H; neither that acceptance nor LG07 approves A11 or concrete mastery rules. All new numbers and rules in this proposal require owner approval before code. The design lease is released.

## Recommendation and current capability

Build one manual Small Crew mastery trial before attempting A11. Defer the other eleven medal sets, mastery rewards and automatic challenge execution. This is the smallest useful predecessor that preserves the master's Estate3/genuine-gold requirement. It does not make A11 ready.

Current source implements twelve ordinary first clears, not bronze/silver/gold. `chDone` is a retained boolean map. Original four challenges award 3/4/4/5 stars and their perks once; the eight helper challenges award their existing once-only Letters/earned helper benefits. Replays do not pay challenge stars, Letters or helper benefits again. There is no persistent medal rule version, manual qualification record, selected A11 order or A11 executor. Ordinary challenge run state, including One brief and Fixed cast metadata, is not a medal record. Historic clears must remain ordinary clears without inferred medals.

There are two separate blockers for A11. First, challenge entry still uses `doPrint(chId)`, mutates live room/wallet, then calls save. The accepted fixed Printing command explicitly refuses active/selected challenges. Second, the available automation cannot bootstrap a newly reset challenge. Publisher resets to tier0; buying tier1 requires three progression sales and its ordinary price. No existing helper makes those first three sales or buys Publisher. Auto-shop buys only hold/contracts/metro/dbl/agent/analyst. Auto-hire buys crew on owned desks; it cannot buy the next desk. A11 cannot be described as merely selecting a challenge and letting current helpers finish it.

Source anchors and SHA256 identities are in [source basis](evidence/LG-08/auto-challenge-design-r1/source-basis.md) and [manifest](evidence/LG-08/auto-challenge-design-r1/source-manifest.json). These are source/math findings, not runtime acceptance.

## Exact proposed base A11 contract, blocked pending prerequisites

This is a future rule for owner review, not an executable candidate. The opted-in Gold trial introduction and successful manual Gold clear may supply that proof together, with no historical backfill. A11 never earns or upgrades medals.

Free, default Off. The player selects an ordered subset of eligible supported Gold challenges in Automation. Start with Small Crew only if it later has a faithful production toolchain. Other Gold records alone do not make unsupported challenges executable. Persist the order and next cursor, with one run at a time. Finish a run, advance cursor once after acknowledged exit, then wrap the selected order. Changes while a run is active apply only to the next start; pending intents retain their exact original command. Empty/unsupported selection waits visibly. Never substitute another challenge.

Base cadence proposal: one start or exit attempt per60 eligible active game seconds in a tenth rotating helper slot. At most one of the nine existing helper services plus A11 services per tick; no second action loop. A completion may acknowledge immediately through its owner; queue the exit/cursor transition for the next fair due attempt. While blocked, reset the A11 elapsed clock tozero and accrue no catch-up. Banana net keeps its separate current timing. Existing helpers retain their own unlocks, settings, prices, reserves, margins and restriction checks. A11 cannot enable or grant another helper.

A11 must reserve the next reset while enabled with a nonempty supported selection, so A10 cannot repeatedly erase the room before challenge entry. Pause A10 sampling/countdown and clear its stale decision on reservation, selected manual challenge, active challenge or pending A11 reset. Preserve A10's saved On/N. Manual next-Printing challenge selection takes precedence and pauses A11 until the player clears that selection. Do not treat `ui.nextCh` as an A11 command. A run starts only with>=1 pending Printing star and the exact selected challenge still eligible. If stars are insufficient, show Waiting for a Printing star; no free entry and no automatic ordinary Printing to manufacture eligibility.

Start uses one acknowledged challenge-entry Printing. It pays the actual pending Printing gain once, resets the room and installs a standard ordinary challenge at its existing goal, not the harder medal trial. Complete acknowledges the actual goal and lifts the constraint without a second reset or repeat reward. Exit records success/cursor once and returns to ordinary production until the next due start with another pending star. No forced exit Printing is needed. Failure/abandon stops A11 locally and requests durable Off; do not silently cycle to a different challenge. Off during a run prevents all later A11 actions; offer Continue manually or a separately confirmed acknowledged Abandon. Off alone does not erase the challenge or cancel a durable entry/clear intent. An already durable intent finishes exactly once, then remains Off locally even if saving Off is still waiting.

Only visible active game, actual Rewards owner/running/guard, no hidden/menu/hosted overlay/Settings/tour/modal/celebration, no work or unsettled choices, no held save/away checkpoint/pending debit/reset/claim, and supported retained metadata may authorize a new action. Saving On must follow a disclosure naming selected goals, room losses, entry Printing stars, zero repeat-clear payout, retained history, helper limits and Off behavior.
