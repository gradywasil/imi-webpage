# LG-01A independent runtime and source review, r1

**Verdict: HOLD.** The default-off candidate has strong source-bound parity and several working native prerequisites, but enabled startup can overwrite an invalid-shaped saved wallet or Ops record. Actual hidden-tab resume, bfcache restoration and reduced-motion media remain unverified. This report is not LG-01A or LG-01 acceptance.

## Material findings, in order

1. **FAIL — enabled startup overwrites readable but invalid-shaped prior records.** `Economy.loadScore()` treats any JSON value without a current `economyVersion` as a legacy numeric save. For the task-owned native fixture `imi-score = "\"25\""` (a JSON string), Classic acquired the lock, backed up the value, then replaced the live wallet with `{"economyVersion":1,"score":0}` and continued booting. `Economy.loadState()` likewise returns `null` for a JSON array. With `imi-ops-v1 = [{"important":"old"}]`, Pixel booted a fresh state; `IMI.ops.saveAcknowledged()` returned `{ok:true}` and replaced the old array with a new object lacking `important`. See [native-invalid-wallet-shape.json](evidence/LG-01/qa-a-r1/native-invalid-wallet-shape.json) and [native-invalid-state-shape.json](evidence/LG-01/qa-a-r1/native-invalid-state-shape.json). The enabled path should reject unsupported existing shapes and present the blocked startup state before any replacement. This is distinct from the approved numeric legacy conversion and from the preserved unknown fields inside valid versioned objects.
2. **UNVERIFIED — mandatory native lifecycle/media lanes.** Neither the prior receipts nor this round prove actual hidden-tab ownership/resume, an actual bfcache restoration with reacquisition, or a pre-load `prefers-reduced-motion: reduce` environment. Property/event injection is synthetic, and the prior history receipt reports a fresh `back_forward` load. Static Low mode and a reduced-motion CSS rule do not establish actual media behavior. The acceptance brief requires these lanes, so the verdict remains HOLD even after the save-shape defect is repaired.
